Privacy

Last updated 7 September 2026. This page describes what actually happens, and each claim below was verified against the running deployment rather than assumed.

Do not upload identifiable patient data. This service runs on ordinary commercial hosting. There is no Business Associate Agreement, and it is not configured for HIPAA-regulated protected health information. Use de-identified, synthetic, or your own test notes.

What happens to a note you submit

When you choose a file, it is read in your browser using the browser's own file API. The file itself is never uploaded.

When you press Match, the text currently in the box is sent to this site's own server so it can be compared against the trial corpus. There it is held in memory for the length of that single request, used to compute the result, and discarded when the request ends. It is not written to disk, not placed in a database, not retained after the response, and not used to train anything.

We verified this by submitting a note containing a unique marker string and then searching the platform's retained logs for it. The marker did not appear.

What this site does not do

  • No accounts. There is no sign-up, no email address, no password, no profile.
  • No cookies. The site sets none, for any purpose.
  • No analytics and no trackers. There is no Google Analytics, no pixel, no session recording, no fingerprinting.
  • No third-party requests. The page loads only its own HTML, CSS and JavaScript. This is enforced in the browser by a Content Security Policy of default-src 'self', so a third-party request would be blocked even if one were added by mistake.
  • No advertising, and nothing is sold or shared.

You can confirm all of this yourself: open your browser's network panel and watch what the page requests, or read the source, which is the same code that is deployed.

Links to ClinicalTrials.gov

Every trial links to its record on ClinicalTrials.gov. Following one takes you to a US National Library of Medicine site with its own privacy policy. We send no information about you along with that link — the page sets Referrer-Policy: no-referrer.

Children

This is a professional research tool and is not directed to children. We knowingly collect nothing from anyone, of any age.
